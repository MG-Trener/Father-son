# Изображения и тестовая сборка 0.4.2 / 16

## Изменения

- `feature-*` теперь использует подходящие сюжеты навигационного набора вместо обрывков школьных/спортивных изображений.
- Нарезка всех наборов учитывает реальные промежутки между объектами, исключая соседние фрагменты.
- Встроенный imagegen создал `assets/brand-source/utility-icons-v2.png` и `achievement-badges-v2.png` с прозрачным фоном. Оригиналы сохранены.
- 29 значков суммарно занимают 625 837 байт (611 КиБ); прежние 28 занимали 3 210 096 байт. Снижение на 80,5% даже с новым конвертом. Семейная сцена переведена из PNG 655 048 байт в WebP 143 224 байта (около −78%). Иконка приложения и заставка сохранены.
- `StoryHero` и `ToolHub` используют градиент с тематическим значком вместо повторения семейной сцены на каждом инструментальном экране. Исправлен приоритет явно переданного emblem.
- Размер фонового изображения привязан к контейнеру: в web больше не показывается только левый край исходника.
- Для писем создан отдельный `letter-v1.png`: конверт заменил микрофон на кнопке «Письма» и гору/путь в разделе капсул времени.

## Проверить на телефоне

1. Установить 0.4.2 / 16 поверх текущего APK, без удаления приложения. Проверить сохранение входа и своей семьи.
2. Главная: оба героя видны в кадре; нижние пять вкладок читаются и нажимаются.
3. Развитие: школа, футбол, шахматы, английский и лидерство имеют подходящие значки, без соседних обрывков.
4. «Эта неделя», «Вместе», «Мы», книга и ритуалы: картинки соответствуют подписям; нет белых прямоугольников вокруг служебных значков и гербов.

6. Закрыть и снова открыть приложение. Для замечания сообщить экран, действие и результат; для визуального дефекта полезен скриншот.
