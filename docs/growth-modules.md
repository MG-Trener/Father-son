# Growth modules

Planned long-lived interactive modules for Arthur's development:

- School: goals, effort, outcomes, lessons learned.
- Football: training/match notes, teamwork, tactical observations, next focus.
- Chess: game result, analysis, critical moment, lesson.
- English: speaking/practice duration, new phrases, confidence, real-life use.
- Leadership: situation, initiative, decision, outcome, reflection.

All modules should write to one family-scoped growth journal rather than isolated feature tables, so multi-year analytics and achievements can be built consistently.
