# Исправления 0.6.1 (Android 21)

## Поведение

- Пустой чат отображается отдельным обычным блоком. Удалён ручной `scaleY`, конфликтовавший с Android-инверсией `scale: -1` в VirtualizedList. Сообщения сохраняют хронологию.
- Свои сообщения чата, воспоминания и текстовые ответы Книги года можно изменять до конца дня создания. Свои голосовые истории можно перезаписывать в тот же срок. Серверная граница — 00:00 Asia/Qyzylorda (UTC+5), исходная дата не меняется. Чужие и прошлые записи остаются доступны только для чтения/прослушивания. Запечатанные письма сохраняют прежние правила.
- При замене голоса сначала загружается новый файл, затем одной транзакцией меняется ссылка записи. Старый файл удаляется лишь после подтверждения. Storage запрещает перезапись файлов и удаление используемого аудио. Потерянный ответ сервера повторяется с тем же путём файла, без дубля истории.
- После остановки микрофона плеер не загружается автоматически; аудио открывается при нажатии прослушивания. Нативные операции сериализованы, асинхронные продолжения после закрытия экрана отменены. Пауза плеера выполняется в layout cleanup до освобождения объекта expo-audio. Повторный stop при unmount удалён. Локальный файл Android читается через expo-file-system File.
- Шахматный ход немедленно показывается локально; до подтверждения виден статус сохранения и запрещён второй ход. RPC возвращает подтверждённую доску в той же транзакции. Старые ответы обновления не откатывают более новую позицию. При ошибке выполняется сверка, при потере связи ход блокируется до обновления.
- Очередь игрока выделена крупным зелёным блоком, сообщением и короткой вибрацией на открытой доске. На других экранах появляется уведомление с переходом к игре; устаревшие приглашения не показываются после ответного хода. Фоновый push по-прежнему требует настройки EAS/FCM.
- Шах выделяется отдельным красным блоком с инструкцией защиты и выделением клетки короля. Мат имеет отдельное сообщение о завершении; пат и другие ничьи не называются матом. Завершение партии видно и в уведомлении вне доски.
- Подписи нижних вкладок подстраиваются под доступную ширину. Добавлен экран восстановления при ошибке React.

## Проверка

- TypeScript; 72 unit-теста; 37 проверок PGlite PostgreSQL. Включены граница местной полуночи, права автора, серверный запрет вчерашних изменений, конфликт редактирования, повтор сохранения аудио, защита Storage, сериализация аудиоопераций, версии шахматной доски.
- Браузерный стенд 390×844 с синтетической семьёй: пустой чат; отправка/изменение сообщения; редактирование воспоминания; переход плеер → перезапись; уведомление о ходе на другом экране. При искусственном ответе через 4 секунды фигура переместилась за ~0,3 секунды. При отклонённом ходе подтверждён откат. Ошибок браузерной консоли в этих сценариях нет.
- Миграция `20261007173349_same_day_record_edits.sql` применена к рабочему Supabase. Проверки Storage и истории миграций пройдены. Существующие семейные записи не удалялись.
- Причина конкретного аварийного закрытия телефона не доказана без Android-журнала. Устранены обнаруженные обращения к освобождённому аудиообъекту и гонки остановки. Браузер и unit-тесты не заменяют проверку нативного микрофона на двух телефонах.

## Проверка на телефонах после обновления

Записать → остановить → прослушать → сохранить → прослушать из архива. Повторить через «Перезаписать сегодня», перейти в другую вкладку во время прослушивания. В шахматах проверить быстрый ход, получение очереди на втором телефоне и отсутствие повторного хода до подтверждения. На следующий день кнопки редактирования должны исчезнуть.
