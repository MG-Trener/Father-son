# Мобильный интерфейс 0.6.0

Дата: 7 октября 2026. Android versionCode: 20.

## Поведение

- Постоянное нижнее меню: Сегодня, Вместе, Развитие, Память, Настройки. Оно находится вне стека экранов, поэтому доступно в формах, чате, шахматах и настройках. Нижний системный отступ Android учитывается SafeAreaView. Повторное нажатие начинает раздел с верхней части; dismissTo удаляет вложенные экраны без ошибочного POP_TO_TOP.
- Постоянный семейный чат, одна кнопка «Позвать на разговор». Приглашение появляется поверх другого раздела; «Я здесь» открывает чат. Собственные, прочитанные и уже отвеченные приглашения не показываются повторно. При недоступном Realtime есть обновление каждые 15 секунд в открытом приложении.
- Шахматы: одна сохраняемая доска на семью, очередность ходов и легальность проверяются сервером. Ходы можно делать в разное время. Уведомление о ходе отключается переключателем. Рейтинга, таблицы побед/поражений и архива завершённых партий нет. Новая партия заменяет законченную.
- Школьное расписание перенесено из MG-Trener/Artur, script.js SHA a8aa6b609b4da44a4c1349617b6ffcb099e14686: дни, уроки, кабинеты, двойные занятия и перемены. Часы используют Asia/Almaty; каникулы 2026/27 взяты из holiday-widget.js. Журналы занятий доступны из расписания и шахмат.
- Книга года: календарные годы и пять тем; ответы читаются и прослушиваются из соответствующей темы. После сохранения открывается готовая запись и ненавязчивое уведомление вместо системного диалога. Старые ответы с возрастом в заголовке доступны в году создания и в общих архивах.
- Воспоминания, голосовые истории и важные события: месяцы, фильтр автора и страницы по 10 записей; в чате страницы по 30. Служебные действия, сигналы и настроение не засоряют историю важных событий.
- Фото из галереи: квадратный JPEG 256×256, максимум 100 КБ; сжимается на телефоне до отправки. На Android файл читается Expo File API. Приватный Storage разрешает заменять только свой аватар; на приветствии показывается выбранное фото.

## Сервер и безопасность

Применена additive-миграция `20261007151944_mobile_social_upgrade.sql`. Данные семьи не удалялись. Новые таблицы chat_messages/chess_games закрыты RLS и прежней защитой сеансов владельца. Сообщения отправляются через RPC с защитой от повторной отправки; прямой INSERT запрещён. Edge Function chess-game проверяет JWT через Auth.getUser, членство через пользовательский RLS и правила chess.js; запись выполняется атомарно с проверкой версии. Сервисный ключ находится только на сервере.

Развёрнуты chess-game и обновлённая send-family-push. В Expo отправляется только общее уведомление и маршрут — без имён, семейных идентификаторов и содержания сообщений.

**Ограничение:** фоновый Android push при закрытом приложении пока не настроен: нет EAS projectId / Firebase FCM credentials. Всплывающее приглашение и оповещение о ходе работают внутри открытого приложения. Отсутствие внешней push-доставки не мешает переписке и сохранению ходов.

## Проверки

- 65 unit tests, включая восстановление шахматной партии, очередность, незаконный ход, устаревшую версию, рокировку, мат и повторение позиции.
- 29 изолированных PostgreSQL/PGlite сценариев: защита владельца, изоляция семьи, идемпотентность сообщений, запрет подделки позиции, атомарная версия доски и права аватаров. Реальные пользовательские данные в тесты не копировались.
- TypeScript, проверка 35 изображений, Expo Doctor 21/21, web export.
- Production read-only invariants: права новых таблиц и функций, закрытый bucket аватаров и согласованность 52 миграций.
- Мобильный браузер 390×844 с синтетической семьёй: чат, приглашение из настроек → чат, ход e2–e4, расписание, сохранение ответа → готовая запись, аватар. Фото 358 КБ сжалось до 17 206 байт, JPEG 256×256. Повторное нажатие «Настройки» сбросило scrollTop с 395 до 0; ошибок навигации нет.

Браузерный прогон не заменяет проверку нативной клавиатуры, системной навигации, микрофона и галереи на двух настоящих телефонах. После обновления обоих устройств: открыть чат → позвать из другого раздела → принять → обменяться сообщениями; сделать по одному шахматному ходу; записать и прослушать ответ; выбрать аватар; проверить нижний отступ при жестовой и кнопочной навигации Android.
