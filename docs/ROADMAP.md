## 0.5 — архитектура + визуальная система

### Data layer

Последовательно вынести из экранов в `src/data/`:

1. meetings + meeting ideas/reactions;
2. growth entries + missions + achievements;
3. yearbook / age seasons;
4. agreements + rituals;
5. voice stories / future letters.

Правило: сначала repository/service и типы, затем перевод экрана, затем дробление UI.

### Крупные экраны

Постепенно уменьшить монолитные routes/screens. Первый приоритет:

- `meeting-plan.tsx`;
- `growth-entry-new.tsx`;
- `future-letter-new.tsx`;
- `growth-journal.tsx`;
- `achievements.tsx`;
- `conversation-cards.tsx`;
- `agreements.tsx`.

### Визуальная система

- перевести новые и редактируемые экраны на `src/brandAssets.ts`;
- не использовать общий atlas как runtime-изображение, если существует отдельный generated PNG;
- унифицировать empty states, section headers, feature cards и achievement cards;
- сохранить палитру: тёмно-синий + тёплый золотой/оранжевый + кремовый;
- использовать папу и сына как эмоциональный визуальный мотив, а не декоративный фон на каждом экране.

## 0.6 — развитие на годы

### Пять направлений

- Школа;
- Футбол;
- Шахматы;
- English;
- Лидерство.

Для каждого направления:
- этапы взросления;
- последовательные skill nodes;
- миссии;
- milestones;
- достижения;
- история прогресса;
- рефлексия после значимых событий.

### «Вместе»

Развивать как главный эмоциональный центр приложения:
- встречи;
- идеи встреч и реакции;
- совместные планы;
- разговоры по карточкам;
- голосовые истории;
- договорённости;
- ритуалы;
- признания;
- письма в будущее;
- общие проекты и приключения.

## 0.7 — Книга года

Сделать Книгу года не просто архивом, а автоматически собираемой семейной историей:
- ключевые достижения;
- лучшие совместные моменты;
- фотографии/голосовые истории в будущем;
- важные признания;
- рост по пяти направлениям;
- встречи и приключения;
- короткие итоги от папы и сына;
- финализация года без потери исходных событий.

## 1.0 — ежедневное семейное приложение

Критерии готовности:
- установка/обновление APK предсказуемы и проверяемы;
- база полностью воспроизводима;
- основные сценарии покрыты integration tests;
- ни один критичный write не доверяет клиенту бизнес-правила;
- приложение одинаково понятно роли папы и роли сына;
- нет экранов-заглушек;
- визуальная система едина;
- данные нескольких лет не требуют изменения фундаментальной схемы;
- пользователь может восстановить историю после смены телефона простым входом в аккаунт.
