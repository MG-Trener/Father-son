# Папа & Я

Приватное Android-приложение для Михаила и Артура, которое помогает оставаться одной командой, даже когда они живут отдельно.

## Концепция

Приложение не является системой родительского контроля. Основные темы: общение, школа, футбол, шахматы, английский язык, лидерство, совместные миссии и многолетняя история достижений.

## Технологии

- Expo SDK 57 / React Native 0.86
- Expo Router
- TypeScript
- Supabase (Auth, PostgreSQL, в дальнейшем Storage/Realtime/Push backend)

## Первый запуск разработчика

1. Установить зависимости: `npm install`.
2. Скопировать `.env.example` в `.env`.
3. Заполнить `EXPO_PUBLIC_SUPABASE_URL` и `EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY` из проекта Supabase `father-son`.
4. Запустить `npm run start`.
5. После первой установки зависимостей обязательно закоммитить сгенерированный `package-lock.json`, чтобы зафиксировать дерево зависимостей.

## APK

`eas.json` уже содержит профиль `preview` с `buildType: apk`. После настройки EAS проект можно собирать как внутренний APK, а production-профиль оставлен под Android App Bundle.

## Безопасность

- В клиент нельзя помещать Supabase `service_role` / secret key.
- Используется только publishable key.
- Семейные таблицы защищаются Row Level Security в Supabase.
- Доступ к семейным данным строится вокруг membership семьи, а не вокруг доверия данным из интерфейса.
