# Визуальный набор «Папа & Я»

Исходники хранятся здесь, файлы assets/generated воспроизводятся командой npm ci или node scripts/generate-brand-assets.mjs. Не редактировать generated вручную.

## Используемые источники

| Источник | Назначение |
| --- | --- |
| app-icon.png, splash.png | Узнаваемая иконка и заставка; сохранены |
| family-hero.png | Семейная сцена; WebP 1280×720 для интерфейса |
| navigation-icons.png | Дом, путь, книга, вместе, семья; эти же сюжеты используются для feature-* |
| growth-directions.png | Школа, футбол, шахматы, английский, лидерство |
| utility-icons-v2.png | Календарь, голос, договорённости, цель, поддержка; прозрачная версия imagegen |
| letter-v1.png | Запечатанный конверт для писем в будущее; новая иллюстрация imagegen |
| achievement-badges-v2.png | Восемь гербов с прозрачным фоном; версия imagegen |

feature-icons.png на самом деле содержит школьные/спортивные мотивы в двух рядах. Он больше не участвует в сборке: прежняя нарезка на пять полос давала обрывки под неправильными именами. Исходник сохранён. Оригинальные utility-icons.png, achievement-badges.png, decor-atlas.png и обзор brand-atlas.webp также сохранены.

## Правила

- Палитра: тёмно-синий, тёплое золото, кремовый и природный зелёный. Семейный стиль без инфантильности для возраста 11–18 лет.
- Семейная сцена — эмоциональный акцент. StoryHero и ToolHub используют спокойный градиент и значок раздела.
- Значки выводить через contain с прозрачными полями. Надписи остаются текстом интерфейса.
- У ImageBackground явно задавать imageStyle с шириной и высотой 100%, чтобы web не использовал исходные размеры картинки.
- Границы нарезки измерены для конкретных исходников. При замене листа проверить размеры и границы в scripts/generate-brand-assets.mjs, не предполагать равномерную сетку.
- npm run check:assets проверяет 29 значков: края, заполнение, ссылки и бюджет размера. Смысл изображения и фон дополнительно проверять визуально.
